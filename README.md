# считалОчка

Простое приложение для учёта трат с монстриком, который подсказывает, как идут дела с деньгами.
Работает в браузере на телефоне и компьютере, ставится на главный экран как обычное приложение и работает без интернета.

**Открыть:** https://sofaleya.github.io/schitalochka/

## Что умеет

- **Записи:** расходы, доходы, возвраты и переводы между своими счетами. Категория подбирается сама по заметке, частые траты записываются в одно касание. Можно добавить свои категории.
- **Копилки и долги:** отложенные деньги не смешиваются со «свободными». У копилки можно задать цель: приложение покажет процент и когда наберётся при нынешнем темпе.
- **План на день** — сколько можно тратить на жизнь: (доход − обязательные платежи − отложить − редкие расходы) ÷ 30,4 дня.
- **Монстрик** — 12 персонажей на выбор или свои картинки. Утром рассказывает, как прошёл вчерашний день, и реагирует на траты: радуется, задумывается, беспокоится, грустит.
- **Прогресс:** звёзды за результат, а не за количество записей. День без трат, день в плане, неделя и месяц в бюджете. Без наказаний за перерасход.
- **«Делю с кем-то»:** трата с ожидаемым возвратом, список «Ждёшь возвратов».
- **Лимиты по категориям,** например «кафе — не больше 6 000 ₽ в месяц».
- **Анализ:** траты по дням и категориям, «Разбор месяца» с прогнозом, сравнением с обычным месяцем, необычно крупными тратами и подсказками.
- **Загрузка банковских выписок (PDF):** Альфа-Банк, Сбер, ВТБ, ОТП Банк, Т-Банк. Перед добавлением все операции показываются на проверку, переводы себе пропускаются, дубли не создаются.
- **Выгрузка:** текст для разбора в чате с ИИ и таблица CSV для Excel за любой период.
- **Поиск по истории** по заметке, категории и сумме.
- **Простой и полный режим.** В полном добавляются регулярные платежи, доходы по датам и раскладка выплат по копилкам.

## Где хранятся данные

Все записи хранятся **только в браузере на устройстве пользователя**, в `localStorage`. На сервер ничего не отправляется: ни записи, ни выписки, ни картинки монстриков. Владелец сайта чужих данных не видит.

Из этого следуют два правила:
- на другом телефоне или в другом браузере приложение будет пустым;
- если очистить данные браузера или удалить приложение, записи пропадут.

Поэтому в приложении есть **резервная копия**: шестерёнка → «Сохранить файл». Файл удобно отправить себе в «Избранное» в Телеграме. Восстановить данные можно там же, в том числе на новом телефоне.

## Установка на телефон

- **Android, Chrome:** открыть ссылку → меню ⋮ → «Установить приложение» или «Добавить на главный экран».
- **iPhone, Safari:** «Поделиться» → «На экран „Домой“».

Если зажать значок, появятся быстрые действия «Новая трата» и «Новый доход».

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Всё приложение: разметка, стили и код |
| `manifest.webmanifest` | Название, значок и быстрые действия для установки на телефон |
| `sw.js` | Service worker: работа без интернета |
| `pdf.min.js`, `pdf.worker.min.js` | [PDF.js](https://mozilla.github.io/pdf.js/) 3.11.174 для чтения банковских выписок (лицензия Apache 2.0) |
| `icon-*.png` | Значки приложения |

Сборка не нужна: это статический сайт без зависимостей и сервера.

## Как обновить сайт

1. В репозитории: **Add file → Upload files**.
2. Перетащить новые файлы с теми же именами, они заменят старые.
3. **Commit changes**.

Через 1–2 минуты GitHub Pages опубликует изменения. У пользователей новая версия подтянется при следующем открытии с интернетом, их записи при этом не меняются.

Данные лежат в `localStorage` под ключом `podkopka-v1`. Его нельзя менять, иначе у всех откроется пустое приложение.

## Добавить банк для выписок

Разбор выписок находится в `index.html`, в блоке `разбор банковских выписок`: функции `BK.alfa`, `BK.sber`, `BK.vtb`, `BK.otp`, `BK.tbank`. Чтобы добавить банк, нужен образец PDF-выписки. Пишется функция, которая по координатам текста на странице собирает операции, и правило в `BK.detect`, по которому узнаётся банк.
