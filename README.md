# считалОчка

Простое приложение для учёта трат с монстриком, который подсказывает, как идут дела с деньгами.
Работает в браузере на телефоне и компьютере, ставится на главный экран как обычное приложение и работает без интернета.

**Открыть:** https://sofaleya.github.io/schitalochka/

## Что умеет

- **Записи:** расходы, доходы, возвраты и переводы между своими счетами. Категория подбирается сама по заметке, частые траты записываются в одно касание. Можно добавить свои категории.
- **Копилки и долги:** отложенные деньги не смешиваются со «свободными». У копилки можно задать цель: приложение покажет процент и когда наберётся: от суммы «Откладываю в месяц», а если её нет, то по раскладке из «Платежей» или по темпу последнего месяца.
- **План на день** — сколько можно тратить на жизнь: (доход − обязательные платежи − отложить − редкие расходы) ÷ 30,4 дня.
- **Монстрик** — 17 персонажей на выбор. Утром рассказывает, как прошёл вчерашний день, и реагирует на траты: радуется, задумывается, беспокоится, грустит.
- **Наряд монстрика:** головной убор (бантик, цветок, монетка, колпак, нимб, поварской колпак, цилиндр, ведьмина шляпа, корона, зимой новогодняя шапка), очки (круглые, солнечные, 3D, сердечки, звёзды) и шесть цветовых оттенков. Предметы открываются с ростом уровня. Размер монстрика на выбор (маленький, средний, большой), а за ним фон на выбор: погода по настроению и времени суток или любая сцена (солнце, облака, дождь, закат, ночь, снег), космос, своя картинка (хранится только на устройстве) или без фона. Можно носить до трёх вещей сразу, каждую поставить пальцем куда нужно, изменить ей размер и поворот. Всё в окне «сменить» у монстрика: вкладки «Монстрик», «Наряд», «Цвет», «Вид». Иногда монстрик сам показывает трюк: подпрыгивает, танцует, подбрасывает монетку, наклоняет голову (во сне и при отключённой анимации в системе трюков нет).
- **День зарплаты:** задай даты в настройках (шестерёнка → «Дни зарплаты»). Если до зарплаты остались деньги, монстрик похвалит и предложит отложить их в накопления. Если число выпало на выходной или праздник, учитывается ближайший рабочий день раньше (календарь РФ на 2026-2027 встроен, на следующие годы загружается кнопкой в настройках).
- **Прогресс:** звёзды за результат, а не за количество записей. День без трат, день в плане, неделя и месяц в бюджете. Без наказаний за перерасход.
- **«Делю с кем-то»:** трата с ожидаемым возвратом, монстрик напоминает о нём, пока деньги не придут.
- **Лимиты по категориям,** например «кафе — не больше 6 000 ₽ в месяц».
- **Анализ:** траты по дням и категориям, «Разбор месяца» с прогнозом, сравнением с обычным месяцем, необычно крупными тратами и подсказками.
- **Загрузка банковских выписок (PDF):** Альфа-Банк, Сбер, ВТБ, ОТП Банк, Т-Банк. Перед добавлением все операции показываются на проверку, переводы себе пропускаются, дубли не создаются.
- **Полный режим** (включается в настройках) — для планирования от зарплаты до зарплаты: вкладка «Платежи» с доходами и обязательными платежами по дням, «Доступно в день» до зарплаты, раскладка зарплаты по копилкам, тип траты и «Финансовое здоровье».
- **Загрузка из своей таблицы** Excel или CSV: траты с проверкой перед добавлением, а план доходов, платежей, накоплений и долгов — по шаблону.
- **Выгрузка:** текст для разбора в чате с ИИ и таблица CSV для Excel за любой период.
- **Поиск по истории** по заметке, категории и сумме.
- **Предсказание** (кнопка на главной): сколько останется к ближайшей зарплате при обычном темпе трат, свои планы вроде «продукты по понедельникам».
- **Нерегулярный доход** (смены, почасовая): «на сколько дней хватит денег», план по самому скромному месяцу, процент с каждого дохода в копилки, «Мне должны», «Сам себе зарплата» из копилки-буфера, подушка с целью в месяцах. Настройка - мастер по шагам.
- **Гибкая раскладка выплаты:** окно с суммами по копилкам, «уложиться в пришедшее», перенос недостающего на следующую выплату или из свободных денег, галочка «уже переведено» у каждой копилки, правка после сохранения («Разложено → Изменить»).
- **Быстрый ввод:** ярлыки на значке (трата, доход, «сегодня без трат»), «↺ как вчера», сумма и дата из QR-кода чека (где браузер умеет читать QR).
- **Итог недели и итоги года** - монстрик сам рассказывает в воскресенье вечером и в конце декабря.

## Где хранятся данные

Все записи хранятся **только в браузере на устройстве пользователя**, в `localStorage`. На сервер ничего не отправляется: ни записи, ни выписки, ни картинки монстриков. Владелец сайта чужих данных не видит.

Из этого следуют два правила:
- на другом телефоне или в другом браузере приложение будет пустым;
- если очистить данные браузера или удалить приложение, записи пропадут.

Поэтому в приложении есть **резервная копия**: шестерёнка → «Сохранить файл». Файл удобно отправить себе в «Избранное» в Телеграме. Восстановить данные можно там же, в том числе на новом телефоне.

## Установка на телефон

- **Android, Chrome:** открыть ссылку → меню ⋮ → «Установить приложение» или «Добавить на главный экран».
- **iPhone, Safari:** «Поделиться» → «На экран „Домой“».

Если зажать значок, появятся быстрые действия «Новая трата» и «Новый доход».

## Как обновить сайт

Любой коммит в `main` (через git или **Add file → Upload files**) запускает GitHub Actions «Тесты и выкладка сайта»: сначала автотесты, и только если они зелёные - выкладка на GitHub Pages. Обычно это 1,5 минуты. Если тесты красные, сайт не меняется, смотри вкладку Actions.

При выкладке в `index.html` вписывается номер сборки, а рядом кладётся `version.txt`. Открытое приложение сверяет их и показывает плашку «✨ Есть обновление».

Если выкладка упала на шаге `deploy-pages` с ошибкой про артефакт (бывает сбой у GitHub), запусти workflow заново вручную: Actions → «Тесты и выкладка сайта» → Run workflow.

Данные лежат в `localStorage` под ключом `podkopka-v1`. Его нельзя менять, иначе у всех откроется пустое приложение.

## Приложение для Android (apk)

Папка `android/` - простая оболочка WebView над сайтом, так что почти все изменения сайта доходят до apk без пересборки. Пересобирать нужно, только когда меняется сама оболочка (`android/**`): это делает workflow «Сборка apk», он кладёт файл в Releases (`schitalochka.apk`), номер версии = номер сборки. Приложение само показывает плашку о новом apk. Для RuStore новый apk загружается вручную.

Что умеет оболочка (мост `AndroidApp` в JS): поделиться файлом, напоминание в 22:00, цвет системных панелей, ярлыки на значке (`res/xml/shortcuts.xml`). Перехват банковских уведомлений временно отключён.

## Памятка для того, кто вернётся к коду

- Всё приложение - один `index.html`. Состояние - объект `S`, сохраняется функцией `save()` в `localStorage['podkopka-v1']`. Ключ не менять.
- Перед основным скриптом стоит маленький «страховочный»: если основной упал при запуске, показывается экран «Что-то пошло не так» с кнопкой «Скачать мои данные». В конце основного скрипта ставится `window.__schOk=true`.
- Производственный календарь: встроен в `RUCAL` на 2026-2027. Новые года загружаются кнопкой в настройках (или сами в октябре-декабре) с isdayoff.ru, запасной источник - xmlcalendar на GitHub, хранятся в `S.rucal`. Без календаря - общие правила праздников (`ruFixedOff`).
- «Что нового»: массив `NEWS` (на экране максимум 2 пункта), старое - `NEWS_OLD`. `APP_VER` менять только когда есть настоящие новости.
- Договорённости по интерфейсу: только тёмные темы; тексты без рода (приложением пользуются и парни); подсказки прятать под «i»; суммы на жизнь считаются только со свободных денег, платежи из копилок не считаются перерасходом; везде чистые суммы за вычетом возвратов.
- Внешние запросы: курсы валют, Яндекс Диск / Google Диск, GitHub (версия apk), календарь. Без интернета приложение работает полностью, кроме этого.

## Автотесты

Основные сценарии (онбординг, добавление и удаление траты с отменой, сохранение данных, режимы, вкладки, монстрик, настройки) проверяются Playwright-тестами в папке `tests/`. На GitHub они запускаются сами при каждом пуше в main и в pull request (вкладка Actions, "Автотесты"). Локально: `npm install && npx playwright install chromium && npm test` (или с уже установленным Chrome: `CHROME_PATH=/usr/bin/google-chrome npx playwright test`). Внешний интернет в тестах отключён, нужные ответы подменяются через `page.route`.
