# Референсы монстриков для Codex

Начни с PROMPT.md и manifest.json в этой папке. Выполни из корня репозитория:

```sh
python3 monster-references/rebuild.py
```

Это восстановит без изменения содержимого два HTML-прототипа из частей: batch1/monster-batch1-v2.html (включает 70 встроенных изображений) и jelly/11-thought.html. Части нужны из-за ограничения размера передачи файла.

В anatomy/images находятся все 19 концепт-листов и нейтральных поз, извлечённые из согласованного каталога (JPEG-копии концептов, не оригинальные полноразмерные PNG). Используй эти пути из нового manifest.json вместо путей к оригинальному ZIP в PROMPT.md. Альтернативный Растенник исключён. 12 HTML Желейника доступны после восстановления; сальтуха первой пятёрки — приоритет. Финальная решимость Желейника была утверждена по GIF с игривой асимметричной ухмылкой и мягкими бровями, без злости. Сам GIF не удалось перенести; не использовать забракованные предыдущие версии.

Оригинальный ZIP, отдельные GIF, отдельные спрайты и отрицательные QA-скриншоты не перенесены. Спрайты первой пятёрки встроены в HTML, их можно извлечь из data URI. Не выдавай прототипы за готовые риги. При необходимости запрашивай недостающие оригиналы. Не изменяй и не публикуй рабочее приложение до приёмки.
