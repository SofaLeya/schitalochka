# Каталог анимаций СчиталОчки

Каталог охватывает 19 персонажей и 13 состояний. При первом открытии все 247 сочетаний имеют статус «К приёмке». У каждого сочетания собственный статус и заметка. Экспорт и импорт JSON доступны в каталоге, импорт объединяет записи по паре «персонаж + состояние» и заменяет совпадающие записи.

## Автономный каталог

Скачайте архив `monster-catalog-offline` из проверки GitHub Actions, распакуйте его и откройте `monster-catalog-offline.html` в браузере. Файл включает слои и концепты. Для переноса замечаний между автономной и локальной версиями воспользуйтесь экспортом и импортом JSON.

Собрать HTML из корня репозитория:

```sh
python3 monster-catalog/qa/standalone.py /tmp/monster-catalog-offline.html
```

## Локальный просмотр

Из корня репозитория:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте [каталог](http://127.0.0.1:8765/monster-catalog/). Для проверки кадра выберите анимацию и перетащите ползунок. Переключатель «Контуры» показывает силуэт, опорную линию, границы кадра и точки крепления. Синие линии обозначают отдельные слои конечностей, охристые — точки на исходном силуэте. На мобильном экране каталог доступен в одной колонке. Автовоспроизведение учитывает системную настройку уменьшенного движения.

## Исходники

- `engine.js` вычисляет позы, тайминг, эффекты и постоянный масштаб каждой анимации. Каталог и захват для приёмки используют один Canvas-движок.
- `art/sources.json` содержит геометрию и разметку в координатах изображений. `art/build.py` готовит прозрачные PNG и генерирует `rigs.js`. Исходные концепты лежат в `monster-references`.
- `catalog.js` управляет показом и хранит заметки в собственном ключе localStorage. Каталог запускается независимо от приложения.

Для повторной сборки слоёв нужны Python, Pillow, NumPy, SciPy и OpenCV:

```sh
python3 monster-references/rebuild.py
python3 -m pip install pillow numpy scipy opencv-python-headless
python3 monster-catalog/art/build.py
```

Два превью, которые собирает `rebuild.py`, и исходные концепты нужны для подготовки ассетов. Каталог загружает готовые слои и использует концепты для сравнения.

## Материалы приёмки

В артефакте GitHub Actions **monster-catalog-qa** находятся 247 GIF, контрольные PNG с фазой в имени файла, восемь контакт-листов на двух фонах, снимки каталога и CSV со статусами. Артефакт хранится 14 дней. Материалы генерируются в проверке pull request.

Чтобы собрать пакет локально, запустите сервер как описано выше, затем выполните:

```sh
npm ci
npx playwright install chromium
node monster-catalog/qa/capture.cjs http://127.0.0.1:8765 /tmp/monster-catalog-qa
python3 monster-catalog/qa/package.py /tmp/monster-catalog-qa
```

При установленном Chromium или Chrome передайте путь к браузеру через `CHROME_PATH` вместо загрузки Chromium. Для упаковки нужны Pillow и шрифт DejaVu Sans. Для прогона тестов используйте `npm test`; отдельный набор каталога — `npm test -- tests/monster-catalog.spec.js`.

## Что сверить на приёмке

- Желейник. Для задумчивости использованы очищенные фазы v6 с переносом существующей P2 к щеке. Точки отрисовываются отдельно. Финальный GIF решимости отсутствует в материалах. В каталоге показана пробная асимметричная ухмылка для сверки.
- Риги используют доступные JPEG и встроенные PNG. Часть конечностей, мимики и деталей остаётся частью исходного силуэта там, где по ракурсу нельзя надёжно восстановить перекрытие. У Осьминожки размечены пять видимых щупалец. У Языкастика и Мохнатика задние крепления остаются открытым вопросом. Количество экземпляров в риге можно проверить в режиме разметки.
- Для сальтухи первой пятёрки взяты два ракурса batch1 v2, для Желейника — два ракурса из его листа, для остальных — воздушная поза и перевёрнутый ракурс. Из-за ограниченного набора исходных ракурсов на промежуточных фазах местами видна смена рисунка.
- Слои век и мимики зарегистрированы по растровым референсам. Стыки, мелкие контуры и выражения нужно принять в каталоге. Каталог проверялся в Chromium на ширине 320, 768 и 1440 px. Android WebView требует отдельной проверки.
